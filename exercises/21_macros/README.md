# 宏

Rust 的宏系统非常强大，但也有些难以理解。
这里不会讲解如何编写功能完备的复杂宏，
而是介绍使用和创建宏的基本方法。

如果你想进一步学习如何编写自己的宏，可以尝试
[macrokata](https://github.com/tfpk/macrokata) 项目。它的练习风格
与 Rustlings 类似，但专门用于学习编写宏。

## 延伸阅读

- [《Rust 程序设计语言》——宏](https://doc.rust-lang.org/book/ch20-05-macros.html)
- [《Rust 宏小册》](https://veykril.github.io/tlborm/)
